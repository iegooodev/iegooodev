## 🚀 Projetos

### 🐄 BoviScan

Sistema voltado para o agronegócio que utiliza tecnologia para criar uma **identificação digital de bovinos através da biometria do focinho**.

`Biometria` • `Rastreabilidade` • `Agronegócio` • `Tecnologia`

---

### 👤 FaceScan

Projeto de **reconhecimento facial para controle de frequência**, desenvolvido com foco em automatizar e facilitar o registro de presença.

`Reconhecimento Facial` • `Automação` • `Tecnologia`

---

### 🐮 Cadastro de Gado — CDG

Sistema para gerenciamento de animais utilizando tecnologias como:

- RFID
- GPS
- Sensores IoT
- Controle de vacinas
- Histórico dos animais
- Dashboards e relatórios
